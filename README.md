## 📖 О проекте
**«Сталь и Пепел»** — это фэнтезийная Action-RPG, разработанная с нуля командой из 4 человек в рамках проектного семестра Самарского университета. Игрок выступает в роли старого мага-мечника, исследуя локации, сражаясь с мобами и боссами, и выполняя квесты.

Главная техническая и геймдизайнерская особенность проекта — **отказ от классического кнопочного каста заклинаний**. Магия активируется исключительно голосом: система офлайн-распознавания речи (Vosk) слушает микрофон, распознаёт русские фразы и передаёт команды в движок Unity через межпроцессное взаимодействие (IPC).

## ✨ Ключевые особенности (MVP)
* 🗣️ **Голосовая магия:** Каст «Огненного шара» и «Торнадо» произнесением заклинаний вслух (интеграция Python + Vosk).
* ⚔️ **Боевая система:** Machine State (FSM) с жесткой привязкой к фазам анимаций (окна для комбо-атак, i-frames при уклонении).
* 🧠 **AI Врагов:** State Machine для мобов (патрулирование по NavMesh, Raycast-обнаружение, преследование, атака).
* 🌍 **Мир и Оптимизация:** Несколько бесшовных и переходных локаций, кастомная LOD-система, Impostors (PNG-билборды для дальних деревьев).
* 🎒 **RPG-системы:** Инвентарь (ScriptableObjects), диалоговая система, квесты, сохранения в JSON.
* 🛠️ **Кастомные Editor Tools:** Собственные кисти для процедурной расстановки растительности и спавнеров мобов.

## 🛠 Архитектура и Технический Стек

Проект построен на компонентной архитектуре Unity. Взаимодействие между системами реализовано через C# Events, Interfaces и ScriptableObjects.

### 🐍 Голосовой движок (Unity <-> Python IPC)
Вместо использования тяжелых API или облачных сервисов, мы реализовали легковесное офлайн-решение:
1. **Python-сервис (`spell_recognizer.exe`):** Использует библиотеку `vosk` (модель `vosk-model-small-ru-0.22`) и `sounddevice` для захвата аудио. Словарь `SPELLS` маппит фразы на ID заклинаний.
2. **Сборка:** Скрипт упакован в автономный `.exe` через PyInstaller, чтобы игрокам не требовалось устанавливать Python.
3. **Связь с Unity:** Компонент `VoiceMagic` запускает `.exe` как скрытый процесс (`System.Diagnostics.Process`), читает `stdout` в методе `Update()` и триггерит интерфейс `ISpell`.

### ⚙️ State Machine & Animation Locking
Одной из главных проблем стала синхронизация логики и анимаций (особенно комбо-атак).
* **Решение:** Анимация разбита на 3 фазы через *Animation Events*.
* **Фазы:** `1. Запрет прерывания` ➔ `2. Окно для комбо (запрет движения)` ➔ `3. Выход в Idle`.
* Внедрена система защитных флагов (`flagAttack`, `flagMovment`), предотвращающая выполнение устаревших ивентов при быстрой смене состояний.

## 🎮 Управление

| Клавиша | Действие |
| :--- | :--- |
| **WASD** | Передвижение |
| **Shift** | Бег / Спринт |
| **ALT** | Кувырок (уклонение) |
| **ЛКМ** | Атака мечом (комбо-система) |
| **E / R** | Взаимодействие с NPC / Подбор лута |
| **I** | Инвентарь |
| 🎤 **"Огненный шар"** | Запуск снаряда по вектору камеры |
| 🎤 **"Торнадо"** | Вертикальный импульс (прыжок) |

> ⚠️ **Важно:** Для работы магии микрофон должен быть выбран в Windows как **устройство ввода по умолчанию**. Задержка распознавания составляет ~1.5 сек, кулдаун между кастами — 1-2 сек.

## 🚀 Установка и Запуск

### Для игроков (Windows)
1. Перейдите в раздел [Releases](https://github.com/VladimirSkiba/Game_PIKme/releases).
2. Скачайте архив `SteelAndAshes_v1.01.zip`.
3. Распакуйте и запустите `SteelAndAshes.exe`.
4. Убедитесь, что микрофон подключен.

### Для разработчиков (Из исходников)
1. Склонируйте репозиторий: `git clone https://github.com/VladimirSkiba/Game_PIKme.git`
2. Откройте папку в **Unity Hub** (рекомендуется версия 2022.3 LTS или новее).
3. Файл `spell_recognizer.exe` **уже включен** в папку проекта и подхватится Unity автоматически при запуске сцены.
4. Откройте стартовую сцену и нажмите `Play`.

## 🚧 Технические вызовы (Problem Solving)

В ходе разработки команда столкнулась и успешно решила ряд нетривиальных задач:

* **Проблема:** Конфликты слияния `.unity` сцен в Git при параллельной работе 4 человек.
  **Решение:** Перевод Unity в режим *Force Text* сериализации, строгое разделение зон ответственности (каждый работает в своей сцене) и вынос всех механик в переиспользуемые Prefab'ы.
* **Проблема:** Просадки FPS на локациях с плотной растительностью.
  **Решение:** Написание кастомных Editor-кистей, которые автоматически заменяют 3D-модели деревьев на 2D PNG-билборды (Impostors) при удалении от камеры, плюс настройка Occlusion Culling.
* **Проблема:** "Призрачные" срабатывания Animation Events при резком прерывании анимации.
  **Решение:** Реализация паттерна "Защитных флагов", которые сбрасываются при выходе из State, блокируя выполнение `Event()`, если анимация уже не активна.
